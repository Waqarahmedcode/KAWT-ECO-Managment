## Administrator activation

The owner-specified email is stored only in private hosting configuration, never in source or screenshots. Its existing verified account can be activated during the build. If no verified account exists, activation waits for a user-initiated signup/confirmation or sign-in callback; no account, password or email is generated by the operator.

Only the configured email is eligible. Database confirmation/verified-identity evidence is checked, the first grant is serialized and audited, and an existing administrator or previous bootstrap prevents another automatic grant. A subsequently revoked administrator is not automatically re-elevated.

Supabase Auth Site URL and allowed redirects should include the canonical HTTPS site and /auth/callback. These project settings cannot be changed with the public key or PostgreSQL credentials; review them in the project dashboard if the email link redirects elsewhere.
